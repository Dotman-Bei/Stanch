[1. BRAND FOUNDATIONS & DESIGN DNA]
--------------------------------------------------------------------------------
The Base Club / SocialFi design aesthetic combines high-voltage Web3 energy,
neobrutalist structural geometry, playful hand-drawn vector doodle overlays, 
and hyper-contrast typography.

Color System:
- PRIMARY ELECTRIC BLUE:     #0038FF  (Core brand backdrop, vibrant energy)
- CYBER VOLT LIME ACCENT:    #CCFF00  (Highlighter, CTAs, conversion pills, badges)
- DEEP ABYSS BLUE:          #001A99  (3D Extrusion text shadows, borders)
- PURE BLACK:               #000000  (Chunky outlines, badge typography, high contrast)
- STARK WHITE:              #FFFFFF  (Text contrasts, primary surface highlights)
- CANVAS LIGHT SURFACE:     #F8F9FA  (Soft rounded tray cards, secondary surfaces)
- FROST GLASS:              rgba(255, 255, 255, 0.20) with backdrop-blur-md

3D Multi-Layered Extrusion Shadow Formula:

Font Stack:

- Interface & Mono: Inter, system-ui, sans-serif / JetBrains Mono

[3. SHADCN/UI & TYPESCRIPT DIRECTORY CONVENTIONS]
--------------------------------------------------------------------------------
Project Structure:
/src
  /components
    /ui                   <-- shadcn core primitives & BaseClub customized elements
      button.tsx
      dialog.tsx
      slider.tsx
      badge.tsx
    /base-club            <-- BaseClub branded system components
      hero.tsx            <-- The flagship interactive Hero
      navbar.tsx          <-- Dual-pill branded navigation with Wallet triggers
      ticker.tsx          <-- Real-time SocialFi crypto ticker tape
      feature-cards.tsx   <-- 3-card bottom tray with connected directional arrows
      staking-calc.tsx    <-- Interactive $CLUB APY yield simulator
      quest-streak.tsx    <-- Viral SocialFi daily claim & tasks tracker
      circular-badge.tsx  <-- Infinite rotating circular SVG badge
      doodles.tsx         <-- ArrowGreenLeft, ArrowGreenRight, ArrowBlack1 & 2
  /lib
    utils.ts              <-- cn() helper for class merge
  /styles
    globals.css

Why /components/ui is mandatory:
- Maintains strict compatibility with 'npx shadcn@latest add' CLI tools.
- Decouples raw unstyled primitives from brand-customized compounds.
- Enables tree-shakable TSX exports across enterprise teams.
